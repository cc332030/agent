= Agent 规范安装

在目标项目根目录创建 `AGENTS.adoc`。

下面代码块内的内容必须**逐字原样**复制到新建的 `AGENTS.adoc` 中：保留全部换行与空行，不得合并、折叠、删除或重排任何一行，不得改写任何文字——逐字符与代码块内容完全一致（仅去除代码块定界符 `----` 与语言标识 `[source,asciidoc]`）。

创建 `AGENTS.adoc`，内容为：

[source,asciidoc]
----
= Agent 规范入口

本项目的 agent 执行规范入口为：

https://agent.c332030.com/AGENTS_COMMON.adoc

读取该入口及其引用的 specs/ 规范，并持续遵守其全部要求。

规范属强制约束：**开工前必须先读取规范再执行**，不得因未读取/记不全而跳过或放宽任何条款。
----

== 已存在 AGENTS 文档

先检查目标项目根目录是否已存在 agent 规范文档（`AGENTS.adoc`）：

* 不存在：直接创建 `AGENTS.adoc` 入口占位。
* 已存在：**不覆盖、不删除**。保留原文档全部内容，在开头添加上面的入口占位；若原文档已指向本入口（`AGENTS_COMMON.adoc` 或其 URL），则不重复追加。项目自身规范优先于通用规范。

== 约束

* 只创建入口占位，不复制规范本体。
* 代码块内容须逐字原样保留（换行与空行不得丢失），禁止改写格式或压缩排版。

完成后告知用户已创建或已融合。
