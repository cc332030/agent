= java 主题下的防线规则

**一道防线一份**（`guards/<防线名>.toml`）：新增或修订一道防线，只碰**它那一份**——
同一主题下的其它防线、别的主题下的全部防线，一个字节都不动。

加载按目录扫描（`script/rules_engine.py` 的 `load_rule_specs`）：把文件放进来就算数，
不必改脚本、也不必在别处登记一份清单。主题只按"这条判据管哪一类事"分组——主题里没有
次序含义，落在哪一份只由它管什么决定。

一份里可以有多条 `[[guards.<防线名>]]`（同一道防线按落点分几处判断是常态），
但**同一道防线只许出现在一个文件里**（两处各写一半时，改了其中之一另一半照旧生效）。
