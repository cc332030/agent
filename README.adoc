= agent 相关

本仓库用于存储 agent 相关信息。目前确定的内容是 **agent 执行规范**。

== 目录结构

* `AGENTS.adoc` — 规范入口与加载调度器（必加载）：定义规范的分类、懒加载与"按项目类型加载且不漏"的规则，并登记全部规范文件。
* `specs/` — 规范分类目录，按"必加载层 / 通用层 / 技术栈层 / 平台层"分层存储：
  ** `specs/core/` — 必加载层：执行原则、规范管理
  ** `specs/general/` — 通用层：通用编码、文档、git、code review、agent 协作、验证
  ** `specs/stack/` — 技术栈层：java、spring、maven、java 语法糖、测试（按项目类型加载）
  ** `specs/platform/` — 平台层：cnb
* `script/` — 配套脚本目录：
  ** `clean-tmp.py` — 清理目标项目 `tmp/` 临时产物的安全脚本（以当前工作目录为项目根，内置路径穿越防护）；无需下载到目标项目，可远程加载执行（详见脚本头部用法）

== 引用方式

规范适用于任何语言、任何项目。引用方式二选一：
* https 公网静态路径（本仓库发布为公网静态站点后的 URL）
* 本地相对路径或绝对路径

规范文件之间以相对路径互相引用，保证本地与公网静态部署下均可正常跳转。

== 使用要点

* 规范按分类懒加载，但"按项目类型加载且不漏"是底线——如 Java 项目写代码必须加载 Java 编码规范。
* 通用规则与某技术栈专属规则分层存放，通用规则不重复收录进各栈。
