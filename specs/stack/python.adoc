= Python 脚本规范（技术栈层）

以下规范适用于以 Python 编写的脚本文件（风格依据：PEP 8 代码风格、PEP 257 文档字符串约定、PEP 20 之"Python 之禅"）。跨所有脚本语言的通用格式规则见 link:../general/script.adoc[]，脚本中的编码规则遵守 link:../general/coding.adoc[]；本文件只收录本栈专属规则。换行符（行尾）的权威口径见 link:../general/encoding.adoc[]「换行符」，本文件只重申本栈的取值。

== 行尾

* **LF，不得 CRLF（L1）**：`.py` 脚本一律 **LF**（Python 能解析 CRLF、但仓库内统一 LF，避免混用与假变更；shebang `#!/usr/bin/env python3` 在 Linux 下带 `\r` 会定位不到解释器，依据：POSIX 对 shebang 行的解析）；完整判据与检出配置见 link:../general/encoding.adoc[]「换行符」「跨平台检出」

== 文件头与解释器

* shebang 用 `#!/usr/bin/env python3`（明确用 python3，不用 python）（通用 shebang 与可执行要求见 link:../general/script.adoc[]「文件格式与编码」）
* 兼容终端编码：脚本可能在不同平台终端运行，涉及中文输出/读取时，在入口统一按 UTF-8 配置 stdout/stderr（如 `sys.stdout.reconfigure(encoding="utf-8")`），避免 Windows GBK 等非 UTF-8 终端乱码

== 入口与结构

* 可执行脚本用 `if __name__ == "__main__":` 作为入口，逻辑放 `main()` 函数中，避免顶层堆砌过程代码，便于被 import 复用与测试
* `main()` 返回 int 作为退出码（通用退出码约定见 link:../general/script.adoc[]「退出码约定」），`if __name__ == "__main__":` 中以 `sys.exit(main())` 结束

== 参数处理

* 命令行参数统一用标准库 `argparse`，提供 `--help`、参数默认值与类型校验；必填参数缺失时 argparse 自动报错并退出非 0
* 参数校验：对路径、枚举值等参数在解析后显式校验合法性

== 错误处理

* 用 `try/except` 捕获可预期的异常，出错时输出清晰错误到 stderr（`print(..., file=sys.stderr)`）并返回非 0 退出码（通用 stderr/stdout 约定见 link:../general/script.adoc[]「退出码约定」）；不静默吞异常
* 临时文件：写入目标项目 `tmp/`（通用规则见 link:../general/script.adoc[]「安全」），配合 `try/finally` 或临时目录上下文管理器清理

== 编码与风格

* 编码规则（命名、注释、避免控制台打印等）遵守 link:../general/coding.adoc[]
* 脚本保持纯标准库优先，避免为简单脚本引入重依赖
