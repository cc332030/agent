= Java 工具类规范（技术栈层）

以下规范适用于 Java 项目的工具类使用。目标：用标准库或成熟工具库替代重复的原生写法，统一代码风格，避免重复造轮子。

== 工具类使用优先级

使用工具类时按以下优先级选择（从高到低）：

* 1. **JDK 标准库自带能力**（零依赖、最通用）：JDK 支持时优先使用，如 `List.of(...)`/`Set.of(...)`/`Map.of(...)`、`Objects`/`String`/`Math` 等原生方法，不为此引入额外依赖
* 2. **项目自有工具类**（项目已引入的工具库）：如项目引入了 ctool4j 等自有库，使用其提供的工具类（如 `CList.of(...)`、`CStrUtils` 等），避免重复实现
* 3. **通用第三方工具库**：尽量使用 hutool 中的工具类替代原生重复写法，如：
  ** `cn.hutool.core.collection.CollUtil`（集合）
  ** `cn.hutool.core.util.StrUtil`（字符串）
  ** `cn.hutool.core.map.MapUtil`（Map）
  ** `cn.hutool.core.util.ObjectUtil`（对象）
  ** `cn.hutool.core.util.ArrayUtil`（数组）

约束：各优先级仅在对应依赖已引入时适用；未引入某库则跳过该层级，不强行引入不必要依赖（依赖调整见 specs/stack/maven.adoc）。

== 工具类使用约定

* 统一入口：同类操作优先用统一工具类（如集合用 `CollUtil`/`CList`、字符串用 `StrUtil`/`CStrUtils`），不散落手写
* 判空处理：优先用工具类判空（如 `CollUtil.isEmpty`、`StrUtil.isBlank`、`ObjectUtil.isNull`），避免手写重复判空
* 判空兜底用默认值工具方法：通用判空兜底原则见 link:../general/coding.adoc[]「判空/默认值兜底优先用工具方法」；Java 中 hutool 提供 `ObjectUtil.defaultIfNull(x, default)`（x 为 null 时取默认）、`CollUtil.defaultIfEmpty(x, default)`（集合空时取默认）、`StrUtil.emptyToDefault(x, default)`（字符串空时取默认）等工具方法，hutool 已引入时直接用，不重复手写
* 工具类自身实现：工具库内部为构建 API 而直接使用原生写法（如 stream、原生集合）属合理实现，不受本规范约束

== 工具类定义（项目自研工具库）

* 项目自研工具库类默认使用 `@UtilityClass`（lombok）：方法、字段不再需要 `static` 关键词，也不再需要手写私有构造方法（lombok 默认生成私有构造器）
