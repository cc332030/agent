= Windows 平台规范（技术栈层）

适用于在 **Windows 上执行**的工作（与用什么语言、什么构建工具无关）：跑命令、起进程、启动桌面应用或带界面的测试。编码与行尾的取值见 `specs/general/encoding.adoc`，批处理语法见 `specs/stack/batch.adoc`，`powershell` 入口见 `specs/stack/powershell.adoc`——本文件只收**Windows 平台本身**的规则。

== 开窗口不得影响正在用这台机器的用户

* **不得把窗口开到用户眼前（L1）**：Windows 上**用户就用这台机器干活**，执行者开出来的窗口会抢走输入焦点、盖住他的画面、打断手上的事。故凡要跑**会开窗口的东西**（桌面应用、带界面的测试、浏览器），一律取**隐藏窗口或后台运行**的形态，成功判据取自程序自身的输出/日志/接口，**不从"窗口弹出来了"看结果**。**判定标准（任一命中即不合规）**：① 以正常可见窗口启动应用、控制台窗口在用户桌面上留着——而它能隐藏或后台启动；② 以"能看见窗口"当作跑起来的证据。
* **要画面就按那个目标取，不接管桌面（L1）**：判据是"看着对不对"时，按 `specs/general/verify.adoc`「需要看显示效果时，取那一个目标自身的画面、不接管用户的桌面」执行；本栈补两条取值形态：① **渲染与画面取到后台或离屏的那一份**（虚拟显示、离屏渲染、按窗口/控件截图——包括**不在最上层、被别的窗口盖住**的那个窗口）；**要的是应用自己的画面时按那个进程取、不靠把它摆到前台**——Windows 的 `PrintWindow`（`PW_RENDERFULLCONTENT`）一类能拿到**不在前台、被别的窗口盖住**的那个进程/窗口的画面，故"只能先切到前台再截"不成立，**该进程全程留在后台**；② **不切换前台窗口、不动鼠标键盘**。**"隐藏/在后台也能达到目的"是取值的边界**——能达到目的就不许把窗口摆到前台。**判定标准**：为看显示效果而把窗口切到前台、抢焦点、用鼠标键盘逐个点按走过场——命中即不合规。**依据**：ISO 9241-110（对话的可控与不干扰：系统不得打断用户当前工作）；「隐藏窗口或后台操作即可达到目的」这一取值属**本集合按上述方向的判据化取舍**。
* **例外只有两类**：① 被判据的就是**用户手动操作**这条路径本身（快捷键、拖拽、系统集成、真实窗口管理器的行为）；② 隐藏/后台/离屏手段在**这台机器、这个版本、这个形态上实际试过取不到**（须写明试了哪个、卡在哪，不得凭印象判"取不到"）。此时**才**动前台窗口，且先说明为什么非这样不可。

== 要跑的那一份须是本次构建的那一份（单实例与安装副本）

**Windows 上这条判据最容易在无声处失效**：装过一次之后，注册表、开始菜单、桌面快捷方式、文件关联里留着的都是**上一份**的路径。于是"双击能打开"成立、"界面亮起来了"成立，而跑的是上一次装的那个 exe——本次构建的那一份**从来没被启动过**。判据本体（对象身份怎么核、什么算证据）在 `specs/general/verify.adoc`「编译/运行验证」的「要跑的那一份须是本次产出的那一份」，本节只给 **Windows 上的取值形态**与**唯一实例挡路时怎么办**。

* **按本次产出目录下的那一个 exe 绝对路径启动（L1）**：启动用**本次构建产出的那一个文件的全路径**，且**绕过壳**——`Start-Process` 取 `-FilePath` 全路径（不是名字、不是快捷方式、不是协议/文件关联唤起），或直接执行那个路径；**不得**取 PATHEXT/`App Paths`/开始菜单/卸载登记项里指向的那一份。**判定标准（任一命中即不合规）**：① 以 exe 名字或快捷方式启动，而磁盘上同名的还有第二份；② 启动前没核过"这个路径是不是本次产出"（产出目录写的是相对路径、当前目录一变就落到别处）；③ 把"装过 / 双击能开"当成"本次那份能跑"。
* **单实例是既有实例时，不得把它当成结果（L1）**：桌面应用多带"唯一实例"（互斥量、命名管道、已存在的窗口消息、锁文件——见 `specs/general/ui-targets.adoc`「外壳能力清单」的单实例一项）：**新的一份一启动就把参数交给既有实例、自己退出**，于是**你看的是旧那份的画面**。**判定标准（任一命中即不合规）**：① 核过映像路径发现启动的进程不是本次产出那一个，仍据其界面下结论；② 把"启动命令返回了、窗口出现了"当成"这一份跑通了"，而**没有任何一个进程跑的是这一份**。**取值按次序取第一条可行的**：① **先退掉既有实例**（它跑的是旧产物，本次验证不需要它；若那是**用户正在用的**，先说明、不得直接杀——用户的窗口被关掉正是本节上一节要防的那类打扰）；② **让这一份不与既有实例争唯一实例**——唯一实例的**标识取自运行期可给的值**（产出目录/一次性后缀/当次端口），而不是写死的一个全局名；**验收判据是"两个都没问题"**：该跑的这一份**真的有进程在跑**（映像路径能核到），既有实例**没被动过**（还在、画面没被它顶替）；③ **改从不需要唯一实例的入口取判据**——命令行开关、`--headless`/离屏形态、接口/日志/程序自身输出（`specs/general/verify.adoc`「验证手法取能出判据的最轻路径」）：**能不开界面就不开**，这条优先于前两条；④ **确要连单实例一并验**（被判据的正是"唯一实例把第二次启动交给既有实例"这条外壳行为）时，**必须**先退掉既有实例再验，且**如实写明**走了这一步——此时判据就是**交接**本身（第二次启动的新进程退出了、参数确实到了既有实例），**不再要求**"跑起来的是新一份"。**反向情形同样如此**：本次验的**就是打包/安装产物**时，"跑起来的是已安装的那一份"是正确的（`specs/general/verify.adoc`「最轻路径」的例外①），但**仍须核过那是刚刚装上去的这一份**——装过之后同名的旧副本还在，等于两份又回来了。

* 依据（标准名/编号）：Microsoft Learn（`Start-Process -FilePath` 按给定路径启动、不经 `App Paths` 与文件关联解析；卸载登记项与快捷方式记录的是**装过的那一份**）、Microsoft Learn（命名互斥量/命名管道是进程间可见的全局标识——唯一实例正是靠它判断"已经有一个在跑"）、ISO/IEC/IEEE 29119（测试对象须可辨识、结果须可追溯）。**「按产出目录的绝对路径启动 + 核进程映像路径 + 单实例挡路时退掉既有实例或让标识取自运行期可给的值」是本集合的判据化取舍**——官方文档只给机制（哪些入口会解析到别的一份、唯一实例靠什么标识判断），**未**规定"验证时该跑哪一份、被既有实例挡住时怎么办"。

== 个人目录（家目录）须每轮现取、不写死

* **个人目录每次现取、取到即用、不写死也不缓存（L1）**：Windows 上**个人目录并不固定在默认路径上**——为了避免重装或换机器时丢数据，用户会把个人目录（含「我的文档」一类）**整体移到另一块盘或另一个路径**。故凡需要"用户个人目录"的取值（副本落点、配置落点、备份落点），一律在处理的那一刻**向系统现取**，取值来源按次序：① Windows 壳登记的 KnownFolder（`SHGetKnownFolderPath`）——它存在注册表里、随改随取；② 取不到才退回环境变量/`~` 那一套（`USERPROFILE` 这类是**登录时**按注册表设上的，进程内改了它不跟着变）。**判定标准（任一命中即不合规）**：① 代码或配置里写出一条家目录字面值（`C:\Users\xxx`、`C:\Documents and Settings\…`）；② 把取到的路径在模块级/启动时算一次就长期持有（下一轮、下一次运行仍用旧值）；③ 只读环境变量而不去问壳，并把"取到的是默认路径"当成事实。
* **命令行的 `%USERPROFILE%` 与"我的文档"是两件事（L1）**：把「我的文档」重定向到别处**不会**改 `%USERPROFILE%`（两者是不同的 KnownFolder），故"要取的是哪一个目录"须按用途取对应的那一个、不得拿 `%USERPROFILE%` 顶替。**判定标准**：需要「我的文档」时用 `%USERPROFILE%\Documents` 拼出来——命中即不合规（拼出来的那个目录在重定向之后已经不是用户实际在用的那一个）。
* **取不到时如实报错、不静默换地方（L1）**：现取失败（壳不可用、退路也拿不到）时报一句错就停，**不得**退到某个"看起来能写"的路径去——换落点等于让"东西在哪"变成环境相关的事实，之后谁也找不回来。**判定标准**：现取失败后仍继续往下走并写出了文件——命中即不合规。
* 依据（标准名/编号）：Microsoft Learn（`SHGetKnownFolderPath` 与 `KNOWNFOLDERID`：KnownFolder 的路径由壳按注册表现算；`USERPROFILE` 与 FOLDERID_Documents 是不同项）、Microsoft Learn（`cmd` 对 `%VAR%` 的展开取值）。**「每轮现取 + 不缓存 + 不写死字面值 + 取不到就报错」是本集合的判据化取舍**——官方文档给的是机制（有哪些 API、各自取哪一处），**未**规定"每次都要现取、不得缓存"。
