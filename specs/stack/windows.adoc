= Windows 平台规范（技术栈层）

适用于在 **Windows 上执行**的工作（与用什么语言、什么构建工具无关）：跑命令、起进程、启动桌面应用或带界面的测试。编码与行尾的取值见 `specs/general/encoding.adoc`，批处理语法见 `specs/stack/batch.adoc`，`powershell` 入口见 `specs/stack/powershell.adoc`——本文件只收**Windows 平台本身**的规则。

== 开窗口不得影响正在用这台机器的用户

* **不得把窗口开到用户眼前（L1）**：Windows 上**用户就用这台机器干活**，执行者开出来的窗口会抢走输入焦点、盖住他的画面、打断手上的事。故凡要跑**会开窗口的东西**（桌面应用、带界面的测试、浏览器），一律取**隐藏窗口或后台运行**的形态，成功判据取自程序自身的输出/日志/接口，**不从"窗口弹出来了"看结果**。**判定标准（任一命中即不合规）**：① 以正常可见窗口启动应用、控制台窗口在用户桌面上留着——而它能隐藏或后台启动；② 以"能看见窗口"当作跑起来的证据。
* **要画面就按那个目标取，不接管桌面（L1）**：判据是"看着对不对"时，按 `specs/general/verify.adoc`「需要看显示效果时，取那一个目标自身的画面、不接管用户的桌面」执行；本栈补两条取值形态：① **渲染与画面取到后台或离屏的那一份**（虚拟显示、离屏渲染、按窗口/控件截图——包括**不在最上层、被别的窗口盖住**的那个窗口）；② **不切换前台窗口、不动鼠标键盘**。**"隐藏/在后台也能达到目的"是取值的边界**——能达到目的就不许把窗口摆到前台。**判定标准**：为看显示效果而把窗口切到前台、抢焦点、用鼠标键盘逐个点按走过场——命中即不合规。**依据**：ISO 9241-110（对话的可控与不干扰：系统不得打断用户当前工作）；「隐藏窗口或后台操作即可达到目的」这一取值属**本集合按上述方向的判据化取舍**。
* **例外只有两类**：① 被判据的就是**用户手动操作**这条路径本身（快捷键、拖拽、系统集成、真实窗口管理器的行为）；② 隐藏/后台/离屏手段在**这台机器、这个版本、这个形态上实际试过取不到**（须写明试了哪个、卡在哪，不得凭印象判"取不到"）。此时**才**动前台窗口，且先说明为什么非这样不可。
