= 依据与来源真实性规范（通用层）

以下规范适用于**所有语言、所有项目**中"引经据典"的场合——规范条目、文档、注释、提交说明、汇报与 review 意见里出现的**标准编号、文献名称、命令与 API、链接、文件路径、数据与结论**。"优先站在前人的肩膀上看世界"的必加载层重申见 link:../core/execution.adoc[]，写代码时的"不得顺口编造"见 link:../general/self-check.adoc[]「知识边界」。

背景：给出来源是为了让读者**知其所以然、能举一反三**；但**来源一旦不实**，危害大于不给——读者会据此去查、去引、去合规，**一个虚构的标准号会污染整条引用链**（下游文档、评审、交付物都会跟着错）。故"出处"的第一要求不是漂亮，而是**真实可溯源**。

== 内部引用（规范/文档/代码/路径）

* **引用必须指向真实存在（L1）**：规范、文档、代码、文件路径的引用须指向**当前真实存在、可追溯**的目标；**不得引用已删除、已改名或不存在的文件**，也不得**凭印象拼路径/文件名**——写之前先确认目标存在（能定位、能打开）。
* **引用当前地址，不写历史来源（L1）**：迁移/拆分/改名后一律直接引用**当前有效地址**；不得保留"原位于…""旧版本文档中的…""由 X 改名而来"一类**历史来源注记**（旧地址可能已无从追溯，注记会让引用悬空，属无用的历史包袱）。
* **路径基准按引用所在位置（L1）**：文档正文中的链接**相对当前文件所在目录**；代码注释中由 IDE/javadoc 解析的引用**相对模块根**。两套基准不得混用，完整规则见 link:../general/doc.adoc[]「文件格式与编码」中「引用路径（一切引用）」条。
* **类名/方法名/接口名不是修辞（L2）**：文中提到的类、方法、接口、模块名须**真实存在于代码中**（可被检索到），不得编造"看起来该有"的名称。

== 外部引用（标准/文献/规范）

* **只写标准名/编号、不附链接（L1）**：ISO/IEC/IEEE、RFC、W3C、OWASP、POSIX 等标准与权威文献，**只写名称与编号**（如 `RFC 2119`、`ISO 8601`、`PEP 8`）——链接会失效或指向非官方转载，名称与编号唯一、可被检索；唯一例外是**个人项目、知名度很低、仅此一处**的出处，须给出链接（依据：ISO/IEC Directives Part 2 对规范性文件引用现行文件与术语一致性的要求）。
* **不得编造编号/名称/章条（L1）**：不得凭印象生成标准编号、版本年号、章条号或文献标题；**无法确证时宁可不引**（"不引"是可接受的结果，"引错"不是）。若为引用而引用、硬凑不相关标准，同属违规。
* **同名相近标准须辨明主体（L2）**：同一主题常有多家标准（国际标准、国家标准、行业标准、事实标准），引用时须**写清是哪一家、哪一版**（如"ISO/IEC 25010（系统与软件质量模型）"），不得用模糊的"依据相关标准"。
* **引用现行版本（L2）**：优先引用**现行有效**的版本；明知已被替代且无特殊理由时，不得引用废止版本（依据：ISO/IEC Directives Part 2 对规范性文件引用"现行文件优先"的要求）。
* **引用不替代规则本身（L1）**：标准只作**依据与延伸阅读**，条款本身须照旧完整写清——"标准怎么说"不替代"本项目要求什么"，也不得借引用**稀释、改写或减弱**原有约束（本项目有明确取舍/更严要求时，须显式写清覆盖点与理由）。

== 事实性数据与结论

* **数据须有来源或为实测（L1）**：性能数字、容量、版本号、日期、阈值、统计结论等，须**标明来自哪里**（实测/官方文档/项目文件），不得用"大约""一般来说"充当数据；无来源的估计值须写明是估计并给出依据。
* **不臆造行为（L2）**：描述某个工具/平台/库的行为时，须依据其官方文档或**实际验证**；无法确证的行为应写明"未验证"，不得以"按常规应该如此"当成事实。
* **命令可执行（L1）**：文档中给出的命令、参数、脚本须**实际可用**（在对应环境验证过或来自官方文档），不得凭印象拼出"看起来对"的命令——一次跑不通的命令会直接误导操作者。

== 无法确证时的正确做法

* **停下并说明（L1）**：确证不了就**明说"未确证/查不到"**，给出已尝试的查证方式，请用户确认或改换方案；不得用虚构内容填补空白（"顺口编一个"比"说不知道"严重得多，见 link:../general/self-check.adoc[]「知识边界」）。
* **标注不确定度（L2）**：必须给结论但证据不足时，显式标注不确定程度与假设前提，便于后续复核与纠正。
