= git 规范（通用层）

以下规范适用于 git 操作。任务临时产物管理见执行原则（specs/core/execution.adoc）「临时产物」条目。

== 文件移动与重命名

* 文件移动/重命名必须使用 git mv（git 按内容相似度识别 rename、保留跟踪历史），禁止用「新增新文件 + 删除旧文件」代替——delete+create 会使 git 历史断裂（旧文件历史丢失），**执行任何文件移动/重命名操作前须先加载本文件确认此规则**；移动/重命名前须先确认源文件已纳入 git 跟踪（未跟踪的新文件先 git add，再从暂存区/工作区 git mv），保证 git 能识别为 renamed；若已用新增+删除造成了 rename 丢失，须同步修复工作区：恢复旧文件后 git mv 正式重命名，再应用内容修改，确保 git 识别为 renamed

== 暂存与提交检查

* 新生成且需保留的文件，默认执行 git add 加入暂存区；git add/commit 前须检查暂存内容，确认无临时文件（`tmp/` 文件夹临时产物、扫描中间产物、构建产物等）被误提交；若发现临时文件已被提交，直接执行 git rm 删除，不得执行 git commit，由用户最终自行提交确认，不得因此中断任务
