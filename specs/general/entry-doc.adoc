= 入口文档的持久化规范（通用层）

以下规范适用于**任何项目**：入口文档（项目根目录的 `AGENTS.adoc` / `AGENTS.md`，下称"入口文档"）是**唯一会被后续会话与另开的新实例读到**的落点。它解决一个问题：**什么信息必须写进入口文档才不会随会话消失**。

本文件是这一判据的**唯一真源**——本集合其他文件（安装文档的入口模板、维护方落点、技术栈落点）只引用它、**不复述**它的条文与判据；需要改判据时只改这里，别处只改"指向"。反过来，"入口文档里具体要写哪几条路径、落点长什么样"属**安装流程的操作细节**，其唯一真源是安装文档（本集合的入口模板由它给出），本文件不抄那几条路径的字面值。判据与工序分家：**这份文件说"该不该写"，安装文档说"写成什么样"**。

== 最小集（必须写进入口文档）

* **规范入口的读取方式（L1）**：入口文档首先是**规范的入口**——写明规范入口地址（或本地落点）与"开工前必须先读取再执行"。后续会话据此重新加载规范，不依赖上一次会话读过。
* **安装文档路径与取规范脚本路径（L1）**：入口文档只放"这是什么、在哪"，**详述交给路径指向的文档**——除规范入口外，须给出**安装文档的路径**（要重装、要更新、要看完整的取法与退路时直接读它）与**取规范脚本的路径**（下一次怎么下载规范、怎么再取一次）。**判据**：另起一个新实例只拿到这个项目时，它按入口文档给出的这几条路径就能走到"装/更新/再取一次"的权威说明，不必回头问用户、也不必把安装须知整套抄进入口文档（抄一遍＝同一事实两处真源，必然各自漂移）。
* **规范副本的检索路径（L1）**：本地副本落在**项目内**时，写明它的路径（如项目内临时目录）；落在项目外（如本机用户级缓存）时，写明"平台用户级缓存目录下按来源分槽的子目录，位置由系统缓存目录决定"。**判据**：新实例按入口文档的说明**能定位到副本**，不必回头读安装过程或自己找。
* **取回与更新方式（L2）**：写明"怎么再取一次/怎么更新"（运行哪个工具、是否以远程为准、落点可否改）。缺这句时，后续会话只能靠猜——猜不中就重新手工下载一遍。
* **跨会话须保留的本项目信息（L1）**：其余**不属于项目自身规范、但要跨会话/跨实例继续成立**的内容，一并写进入口文档（典型：规范副本落点、本机与项目共用的约定、安装时使用的来源地址）。**判定标准**：出现"只有本次会话知道、下次得重问一遍"的信息，且它确实影响后续执行——即命中：该信息本应写进入口文档。

== 最小集与边界（写什么、不写什么）

* **项目自身规范优先（L1）**：项目自己写的规则写进**入口文档的项目自身内容**（或项目自己的规范文件），**优先于**通用规范、且**不因重新执行安装被改写或删除**。入口文档同时承载两类内容（入口占位 + 项目自身规则）时，重写入口占位**不得**动项目自身规则。
* **临时产物不放入口文档（L1）**：进度记录、运行日志、扫描中间结果、一次性结论属**临时产物**，按 `tmp/` 约定存放（见 link:../core/execution.adoc[]「临时产物」），**不写进入口文档**——否则入口文档会被易失内容灌满，真正的持久约定反而被淹没。**判据**：这份内容下次还要用吗？要＝持久；不要＝临时。
* **同一信息只写一处（L1）**：入口文档里的持久信息与项目其他文档、代码注释之间**不得各写一遍**（两处真源必然各自漂移）；入口文档**写不下的详述交由它所指向的文档承载**，入口文档只留"这是什么、在哪"（判据见 link:doc.adoc[]）。
* **每次安装只动入口（L2）**：重复执行安装时，入口文档的**项目自身内容原样保留**；安装只更新它自己写入的那部分（入口占位与持久信息节），不替项目改写别的文件。

== 与"会话结束就丢"的分界（可核对的问句）

判断一条信息该不该落进入口文档，只问一句：**"另起一个新实例、只给它这个项目，它还缺什么才接得上？"**

* 缺规范入口、安装文档路径、取规范脚本路径与副本位置 → 进入口文档（上「最小集」前四条）；
* 缺某条本项目约定（如"本机的副本落点在哪、来源取哪个地址"） → 进入口文档的持久信息节；
* 只缺"上次做到哪一步、当时怎么查的" → 属临时产物，按 `tmp/` 约定处理，不进入口文档。

依据（标准名/编号）：**ISO/IEC Directives Part 2 与 ISO/IEC/IEEE 29148（信息须落在可追溯的落点、要求须可复核，不得只存在于过程叙述里）**、**ISO 10007（配置管理与变更控制：配置项的持久化位置须明确）**；"以入口文档为唯一持久落点、按最小集判定"是本集合的现场判据化表达。
