= 代码安全规范（通用层，跨语言）

以下规范适用于**所有语言、所有项目**的编码活动。某语言/技术栈专属的安全写法见 `specs/stack/` 对应文件（如 Java 的反射与序列化约束见 link:../stack/java.adoc[]）；通用编码见 link:../general/coding.adoc[]，脚本安全见 link:../general/script.adoc[]，依赖选择见 link:../general/dependency.adoc[]。

依据：OWASP Top 10 与 OWASP ASVS（应用安全验证标准）的风险分类、CWE（Common Weakness Enumeration）的弱点编号体系；鉴权与会话相关另参考 IETF RFC 6749（OAuth 2.0）、RFC 9700（OAuth 2.0 安全最佳实践）。本文件只收录**跨语言通用**的安全底线，具体实现按其语言的权威安全指南执行。

== 输入与输出

* **不信任任何外部输入（L1）**：请求参数、请求头、路径、Cookie、消息体、文件内容、环境变量、第三方返回等一律视为**不可信**，使用前须校验（类型、范围、长度、格式、白名单）；**不得把未校验的外部输入直接拼入 SQL、命令、路径、模板、日志或响应**。
* **输出编码/转义（L1）**：把数据写入不同目标时按该目标上下文做编码——HTML 转义、URL 编码、JSON 转义、SQL 参数化；不得依赖"输入已经过滤过"而省略输出编码（两类防护不可互相替代）。
* **路径与文件名来自外部时须防穿越（L1）**：先规范化（`realpath`/`normalize`）再校验目标落在允许范围内，拒绝 `../`、绝对路径与符号链接越界（脚本场景见 link:../general/script.adoc[]「安全」）。
* **反序列化与模板（L1）**：不得反序列化不可信数据为可执行对象（多语言通用的反序列化漏洞，CWE-502）；模板渲染不得用外部输入拼模板源码（服务端模板注入）。

== 认证、授权与会话

* **认证与授权分离（L1）**：认证只回答"你是谁"，授权只回答"你能做什么"；**每个敏感操作都须在服务端校验授权**，不得以"前端已隐藏入口""网关已拦截"代替服务端鉴权。
* **不自行发明加密与认证（L1）**：口令存储用专门的慢哈希（bcrypt/scrypt/Argon2 一类，禁止明文、MD5/SHA-1 单次哈希、可逆加密）；加密与随机数一律用标准库/权威实现，**禁止自研密码算法、自造随机数、手写令牌格式**（口令与随机数要求另见 RFC 8018 PKCS#5/PBKDF、NIST SP 800-63B；随机数须用密码学安全随机源）。
* **会话与令牌（L1）**：令牌不得写入 URL 查询参数、日志或错误信息；会话标识须可失效（登出即失效、改密后失效）；比较令牌/签名须用**恒定时间比较**，防止时序侧信道（CWE-208）。
* **最小权限（L1）**：数据库账号、服务账号、容器与进程权限按**最小必要**授予；不得用管理员/超级用户权限运行常规业务代码。

== 敏感信息

* **不硬编码密钥（L1）**：口令、令牌、私钥、API Key、连接串凭据**不得写进源码、测试、配置样例、文档或提交历史**；须经环境变量/密钥管理外部化（依据：The Twelve-Factor App 的 config 原则，见 link:../general/ci-cd.adoc[]）。
* **日志与报错不落敏感信息（L1）**：日志、异常信息、报错响应中不得出现口令、令牌、身份证号、银行卡号、手机号等敏感字段；确需定位时做脱敏（掩码）处理。
* **错误不泄漏内部细节（L2）**：返回给使用方的错误信息不得暴露堆栈、SQL、内部路径、内部主机名与版本（CWE-209）；内部细节只进服务端日志。

== 依赖与供应链

* **依赖须来自可信来源并固定版本（L1）**：依赖、构件、镜像、脚本一律来自官方/可信仓库，并固定到**经实际验证的具体版本**；不得使用 `latest`/浮动版本、不得从不明来源下载（可验证性与"外部资源禁止本地下载"另见 link:../general/verify.adoc[]「编译/运行验证」、版本固定见 link:../general/ci-cd.adoc[]）。
* **引入依赖前先评估（L2）**：新依赖须评估其维护活跃度、许可证与已知漏洞，避免为小功能引入大依赖；已有等价能力时优先复用（见 link:../general/dependency.adoc[]）。
* **及时修复已知漏洞（L1）**：已知存在严重漏洞的依赖版本须升级；无法升级须在代码注释或文档中记录原因与风险（状态标记）。

== 安全默认值

* **失败要关闭（fail-closed）（L1）**：鉴权、校验、配置缺失等情况下**默认拒绝**，不得默认放行；异常不得绕过安全检查（错误路径也须执行授权与校验）。
* **调试开关不得进生产（L1）**：调试模式、详细报错、绕过鉴权的后门、测试账号等不得在生产配置中开启（CWE-489）。
* **安全相关不可选项化削弱（L2）**：不得为了兼容或方便提供"关闭安全检查"的配置项；确需时须显式命名、默认关闭并在文档中标注风险。
