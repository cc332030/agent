= 通用工具/库类项目文档规范（项目类型层）

以下规范适用于**通用工具/库类项目**（以可复用组件/库/工具为主、要求每个类在设计时保证绝对正确与绝对可维护性的项目）的文件/类粒度文档组织。**仅在项目自身规范中主动声明为"通用工具类项目"时才加载**（声明方式与检测见 `AGENTS_COMMON.adoc`「分类与懒加载」项目类型层）。普通业务项目不适用，不加载本规范。

== 粒度

* 需要时，**一个文件/一个类可对应一个文档**，按模块/项目需要决定是否细分到类，不强制逐类建文档；文档对应到某个具体代码/脚本/类文件时，按「文档命名须与源文件一致」（link:../general/doc-design.adoc[]）命名。

== 示例结构

仅在需要文件/类粒度文档时参考（仅示意，非强制）：

```
<module>/
├── src/.../<包路径>/Foo.java     # 代码
├── Foo.java → 对应 doc（见下）
└── doc/
    ├── README.adoc               # 模块级索引（总览模块职责、关键文档）
    └── <镜像路径>/               # 与关键代码结构对应
        ├── Foo.adoc              # 单文件/单类对应文档（粒度示例）
        └── <功能>.adoc …         # 模块内功能/组件文档
```
