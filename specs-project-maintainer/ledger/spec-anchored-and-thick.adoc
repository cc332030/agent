== 两件事各自落在哪

* **锚定**：判据本体（三档深度）仍在 `specs/general/spec.adoc`「规格的维护深度（默认只服务本次任务）」；**本项目取哪一档**在 `specs-project-maintainer/spec-lifecycle.adoc`「本仓库的规范条目取哪一档规格」——一处给判据、一处给取值，不是重复。
* **写厚**：判据本体（内容与判据）在 `specs/general/spec.adoc`「规格写到什么程度（内容与判据）」；机械抓手是引擎步骤 `shape_ban`，规则数据在 `script/specs-rules/spec/guards/check_spec_driven_guard.toml`；反例分两处（`TestCheckSpecDrivenGuard` 四条 + `TestShapeBan` 五条）。
* **依据**：`library/adoption.adoc` 补一段（三档深度由外部材料给，而"默认 first / 规范条目自己不带长期规格 / 单条一句"是本集合的判据化取舍；以及"写厚必须单独拦"的代价来自同一份评述）。
