== 这件事各自落在哪

* **判据本体**：`specs/general/doc-lifecycle.adoc`「功能全览（项目现有行为的唯一视图）」。
* **机械抓手**：`check_feature_overview_guard`；规则数据 `script/specs-rules/doc/guards/check_feature_overview_guard.toml`。
* **与既有落点的边界**：需求事件流（`doc/` 阶段目录、变更日志、逐轮记账）记"什么时候要过什么"；功能全览记"现在有什么、什么样子"。两者不互相替代，全览不按时间分份。
