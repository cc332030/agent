= 公共任务提示词（入口）

本文件是**公共任务提示词**的统一入口与登记索引。提示词按任务场景组织、复制即可直接使用，用于让 AI 干活时不漏步、不偷懒、高质高效。**提示词不是规范**：不随 `specs/` 分发、不进规范加载链。

== 访问与解析

* 提示词正文存放于本文件所在目录下的 `prompts/` 子目录，与规范 `specs/` 相互独立、互不干扰。
* 引用方无需引入本入口：提示词按需打开对应文档，把其中 `[listing]` 代码块内的文字**完整原样**复制给 AI 作为任务指令即可。
* 提示词措辞通用、不依赖具体技术栈；项目已接入 agent 规范时，AI 读取项目规范入口后自行遵守规范。

== 提示词登记（按任务场景）

* link:prompts/review.adoc[] — **项目问题检查修复**：对项目做一次全量检查并**修复问题**——读取规范、同步主分支、全量检查代码/文档/测试问题成清单、**明确无争议的问题直接修复、文档与测试用例问题直接修复**、**不明确或有争议的问题集中确认后处理**、回归自检、验证通过后提交并创建 PR 合入。**以检查修复为主、没有问题原则上不重构**（不得夹带重构性质改动）。
* link:prompts/refactor.adoc[] — **项目重构**：对项目做一次**全量重构**并在重构中保持行为不变——读取规范、同步主分支、逐模块检查现状并输出重构方案（含预期收益与取舍）、实施结构重构、补齐文档与用例、性能对比与迭代优化（仅对判定为性能敏感点的代码做性能测试，不乱加也不漏）、回归自检、验证通过后提交并创建 PR 合入。**以重构为目标：检查必须做（是重构的前提），但产出必须是真正落地的结构改动，不得只检查/只出报告**。

* 二者分工（**重点不同、勿混用**）：link:prompts/review.adoc[] 以"**检查修复问题**"为目标——检查出问题就修，无问题即结束，原则上不重构（明确无争议的直接修，不明确/有争议的先确认）；link:prompts/refactor.adoc[] 以"**重构**"为目标——检查服务于重构，产出必须是结构改动。**review 时不得顺手重构无关紧要的代码，重构时不得只检查/只出报告。**

== 维护约定

* 新增提示词：在 `prompts/` 下新增文件（命名与任务场景对应，正文含文档说明 + `[listing]` 可复制代码块），并同步在本文件登记，文件必须真实存在。
