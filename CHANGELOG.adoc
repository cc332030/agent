条目撰写规则见 link:specs/general/changelog.adoc[]，版本与倒序机制见 link:specs/general/doc-design.adoc[]「版本与变更记录」；**本文件的变更条目不适用于 `specs/` 规范文件本身**——规范变更由其 git 历史承载（见同节）。
