= 本项目任务提示词：优化公共规范

**只对本项目（本仓库 `cc332030/agent`）生效**的一次性**公共规范全文优化**任务提示词——**不对其他项目成立、也不要复制到其他项目执行**（判据源与对象都只在本项目里）。非规范内容，不随 `specs/` 分发、不进规范加载链；由本项目维护方自己使用。

**主侧重（方向性前提，先读）**：**按现行判据把公共规范全文过一遍、把冗余与无效内容收敛掉**——产出是**优化后的规范文本**（重复收敛为一处定义 + 引用、表述压到承载为止、空壳与不可达内容删除或补齐），**不是**一份"哪里可以优化"的报告，也**不是**改写规则本身；判据一律取现成的，**本命令不新立判据**；**内容不得减少**（只换承载位置或压掉重复表述）。检查是手段、优化是目标；侧重不符即方向错误（要**改规则**用维护方的条目准入与自身重构口径，要**改方向**用 `prompts/refactor.adoc`，二者不与本命令混用）。

2. 判据与扫描面（**判据一律取现成的、本命令不新立**——本命令自定的只是**扫描面的分类**（下列七类），每一类的**判定标准一律回指现成判据**、不另写一份；本次要新增或改写的每一句文本都属「**调整内容一类需求**」（新增与调整同属一类），动手前须按 `baseline-and-compat` 的先查口径（**先检索现成可参照的标准与更优的设计**——查到了就用更优的、查不到要说得出查证方式）走一遍）：加载维护方自查层的**规范集合自身重构**与**条目准入与定级**、通用层的**精炼性**、**信息密度**与**数据字典**，按它们逐条扫。扫描对象是**本项目的全部内容、不限于规范集合**——**公共规范**（`AGENTS_COMMON.adoc` 与 `specs/`）、**维护方自查层**（`specs-project-maintainer/`）、**公共任务提示词与公共片段**（`prompts/`，**含本命令文件自身**——它同样会被读出、同样会有冗余与无效内容，不得把自己排除在外）、**图书馆**（`library/`）、**本仓库自身工具**（`script/`）、**根目录文档与配置**（`AGENTS.adoc` / `PROMPTS.adoc` / `README.adoc` / `PUBLIC.adoc` / `index.html` / `.cnb.yml` / `.github/` 等），**一个都不漏**。扫描面**至少**覆盖：① **重复表述**——同一件事在两处以上各写一份完整表述（而非"一处定义 + 引用"）；② **精炼性**——重复面是必查项，"说不出查了哪些角度"即视为未查；③ **信息密度**——单处里没有承载的句子（复述、空话、同义反复、铺垫、"只说自己做了什么"）与不承载信息的限定语；④ **数据字典**——名称的定义重复出现、落点不唯一、名称条目未一行一个、上游落点被下游名称撑大；⑤ **多余内容**——空壳文档/空目录与索引、无实质内容的章节、为对称凑数的条目；⑥ **无效内容**——已被证否的旧口径、"定义了却没有判定标准"的口号式条款、判据被压成骨架而只剩轴名；⑦ **不可达内容**——指向已删除或不存在的文件/节名的引用、悬空引用与历史来源注记、被 moved 后加载不到的内容。清单写入 `tmp/` 作核对依据，**本步只扫不改**；**`tmp/` 不可用时就地降级**（工作区只读时，清单写进本次汇报正文，不因此跳过扫描）。
3. 按固定顺序落地：**先判归属** → **再判层级** → **再判重复** → **最后压缩表述**（**顺序不可颠倒**——一步没做完就做下一步，会把"放错位置的内容"直接删掉；四步各自的判据与判定标准**以维护方自查层「规范集合的自身重构」为准**，本处只给顺序这一个取值）。拆不拆另判：三条硬条件同时成立才考虑拆、**默认不拆**，拆了须逐项过"拆分后的自洽核对"。
4. 边界与防误删（**L1，本命令最容易出事的地方**）：**内容不减少优先于删冗余**——删的只能是**重复表述本身**，被删处须留下**可达的引用**；"这一段很长"不构成删除理由，**只有"这一句没有承载"才是**；**判不准是否重复的一律保留**（宁可冗余不可缺失）。**只减冗余、不改规则**：条文的级别、判定标准、取值与生效面一律不动（承压缩表述时"必须/不得"仍在、判据仍在、依据名仍在、级别未降）。**报告落点用既有词**（冗余 / 无效 / 不可达一类），不新造术语。
5. **逐处核内容未减少（L1）**：对**行数与体量变化异常的每一处**逐处核对——原句承载的事实/决策/取值在新落点仍可查到（按条目级判据句核，**不得只看轴名是否齐全**）；删除的每一处都能指出"重复的是哪一处、真源在哪"；被移动的内容在新位置**可被正常加载**（登记与加载触发方式跟着一起搬）。删改面较大的文件须另给一张"删了什么 → 真源落在哪"的对照清单，**随交付一并给出**。
