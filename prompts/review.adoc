= 公共任务提示词：项目问题检查修复

面向任何项目的一次性**全量检查 + 问题修复**任务提示词。非规范内容，不随 `specs/` 分发、不进规范加载链，供用户在给 AI 下达任务时复制使用。适用于已接入 agent 规范的项目（AI 读项目规范入口即可），正文措辞通用、不依赖具体技术栈。

**本提示词以"检查修复问题"为主，不是重构任务**：只修复确实存在的问题，**没有问题原则上不重构**——不得为"顺手""看起来更好"而改动无问题的代码（要主动重构请用 link:refactor.adoc[]，二者分开）。

对本项目执行一次全量检查并修复问题。要求不漏步、不偷懒、高质高效：严格按下述步骤完整执行，任一步未完成不得进入下一步；全部完成并验证通过后才允许提交，不得提前收尾或中途提交。

1. 规范与基线：先读取并遵守项目规范；将主分支更新到最新并同步到当前分支，确保基于最新代码工作。
2. 全量检查：逐模块检查全部代码与文档的问题（代码：规范符合性、重复/坏味道、命名、注释、异常与边界、安全隐患、日志、资源与缓存生命周期等；文档：内容与代码不符、描述缺失/过时、格式与命名不规范等；测试：用例缺失/断言无效/编号与文档不一致等），分级编号成清单写入 tmp/ 作核对依据（每项须标明类型：代码问题/文档问题/测试问题，以及判定"明确"还是"待确认"），不得遗漏模块与文件。**本步只检查与记录，不改任何代码或文档**（改动一律在第 3、4 步进行）。
3. 直接修复（仅下述两类，其余不动）：**明确有问题的、无争议的问题直接修复**——适用：违反项目规范、明确的缺陷或错误（编译/运行错误、逻辑错误、NPE、资源未释放、并发问题、性能隐患等），以及**文档问题与测试用例问题**（内容与代码不符、描述缺失/过时、格式命名不规范、用例缺失或断言无效、编号与测试文档不一致等，此类直接修复、无需确认；但若该修复会改变既有行为或对外契约，则转第 4 步待确认）。修复须遵循规范、做最小目标改动，不擅自扩大改动范围；有取舍的在代码注释与设计/测试文档记录依据与边界。**没有问题的不重构**：不得修改无问题的代码，不得做与问题无关的"顺手重构/优化/重命名/挪动代码/调整格式"；仅当不重构就无法修复该问题、或重构本身就是该问题的修复手段时，才允许改必要部分并说明理由。**重构性质、非问题驱动的改动不得在本任务中夹带**——需要时改用重构提示词（link:refactor.adoc[]）。
4. 待确认问题：**问题不明确、有争议、或可修可不修的，一律先确认、不直接改**——如是否属于问题的判断有分歧、有多种可选方案、规范未明确、会改变既有行为或兼容性、影响面不清（如涉及既有对外契约/公共 API/其他模块调用）等；"可修可不修"指不影响正确性与可维护性、属风格偏好或收益极低的改动（过于细节、无实际影响的问题按规范矫情原则不作提示）。对此类问题：在 tmp/ 清单中整理出**确认清单**（逐条写明：问题描述、涉及文件与位置、疑似原因、可选方案与各自影响、建议与理由、若不处理的后果），**一次性集中向用户确认**，不得擅自改动、不得只确认一部分就动手、不得边改边问；未获确认前保持原状，确认后再按第 3 步规则修复，可在本任务内继续完成。判断不准时按"待确认"处理，宁可确认也不要误改。
5. 完善补齐：同步补注释、更新设计/测试文档、补齐缺失用例（文档与用例问题按第 3 步直接修复）；不新增与本次问题无关的内容。
6. 回归自检：逐一复查全部修复点，确认未引入新问题（无新增编译/静态警告、不破坏既有行为与用例、不影响调用方）；对第 4 步确认后修复的部分一并复查。
7. 最终验证：提交前跑**全量编译与全量测试**，须完全通过且满足规范——编译/构建无错误无警告、全量测试按实际统计全部通过、无规范违规；不满足不得进入提交步骤，须先修复再重跑。
8. 提交并创建 PR：**不允许直接提交或推送分支（为 PR 建的分支除外）**——改动一律在为本次改动新建的 PR 分支上本地提交并推送，不得直接向目标分支（主分支等）提交/推送/合并；目标分支只能通过 PR 经**人工 review** 通过后合入，不得跳过 review。全部完成并验证通过后在 PR 分支统一提交（一次或合理分批），提交前核对无 tmp/ 等临时产物与无关文件，随后推送 PR 分支并创建 Pull Request。若本地环境无法推送/创建 PR（如无权限、远程不可达），则提交保留在本地 PR 分支上、不推送不合并，说明 PR 未创建及原因，交由人工后续处理；仅在 CI 等自动化流程中执行而未合入的改动，本次内容会随之丢失，须以 PR/人工确认的方式合入保留。

完成后汇报：各步骤执行情况、问题清单（编号）与处理状态（已修复/待确认/不处理及原因）、待确认清单的确认结果、验证结果、提交信息。
----
